# Diagramas históricos

Estos diagramas corresponden a la **primera versión del proyecto** (mayo de 2026), cuando PulseUp era una aplicación de seguimiento de hábitos (ejercicio, alimentación y sueño). El módulo de hábitos fue retirado (tarea técnica TK001) y el producto se reorientó al entrenamiento con plan semanal.

Se conservan por trazabilidad. **No describen el sistema actual.** Los diagramas vigentes están en las carpetas `actividad/`, `secuencia/`, `casos-de-uso/` y `bpmn/`.

| Archivo | Qué mostraba | Reemplazado por |
|---|---|---|
| `SEQ-03-ver-habitos-y-calendario` | Ver hábitos y calendario | `SEQ-09-marcar-dia-cumplido-y-racha` |
| `SEQ-04-registrar-habito` | Registrar un hábito | `SEQ-06-agregar-ejercicio-al-plan` |
| `SEQ-05-marcar-habito-cumplido` | Marcar un hábito como cumplido | `SEQ-09-marcar-dia-cumplido-y-racha` |
| `BPMN-01-registro-y-seguimiento-habitos` | Registro y seguimiento de hábitos | `BPMN-01-armar-plan-semanal` y `BPMN-02-entrenar-y-marcar-el-dia` |
| `UC-01-casos-de-uso-habitos` | Casos de uso con hábitos | `UC-01-casos-de-uso-general` |
